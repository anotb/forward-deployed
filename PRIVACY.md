# Privacy

Forward Deployed consists of skill instructions and package metadata. It has no hosted backend, telemetry, publisher-controlled data collection, or runtime executable helpers.

The skills guide the AI host in carrying out the user's work, including research or use of connected tools when appropriate. Those interactions remain governed by the host, the connected service, and the user's permissions and settings. Installing this package grants no access to external systems.

Engagement material can contain confidential information. Use a host and output destination appropriate to the material and preserve its access scope. Do not include client records or credentials in public issue reports.
